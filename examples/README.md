# 示例目录

这个目录按学习阶段组织。

## Python 基础

- `python/01_text_tool.py`：文本处理
- `python/02_http_json.py`：HTTP 和 JSON
- `python/03_fastapi_app`：FastAPI 最小接口
- `python/04_fastapi_routes`：常见 HTTP 方法

## AI 应用主线

- `ai/01_chat_api`：DeepSeek 聊天接口
- `ai/02_chat_history`：带聊天历史的接口
- `ai/03_sqlalchemy_database`：SQLAlchemy 数据库版本
- `ai/04_rag_document_qa`：RAG 文档问答
- `ai/05_background_tasks`：后台任务和状态查询

## Go 补充

- `go/01_struct_and_slice.go`：结构体和切片
- `go/02_http_server.go`：Go 原生 HTTP 服务

Go 当前不是主线，后续会作为 AI 网关和后端服务补充。
